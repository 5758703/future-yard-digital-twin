# 未来院区数字孪生

## 需求来源与范围
依据用户提供的《楼宇数字孪生.md》。交付可本地运行的 Vue + Three.js 演示项目与 Blender 场景生成/导出脚本。没有真实测绘、BIM、设备协议及视频流，因此几何、遥测、天气、人员、告警均为模拟，界面持续标识。所有空间使用米制局部坐标，稳定 ID 贯穿建筑、楼层、房间、设备、告警和工单。

## 设计
- 深蓝灰工作台，以建筑沙盘为视觉中心；青绿表示在线/选中、橙红表示异常。
- 顶部五专题、左侧空间树、中央三维视图、右侧业务详情、底部运行趋势。
- 院区 → 楼栋（楼层分离）→ 楼层（房间剖切）→ 房间，面包屑和场景点击双向联动。
- 6 栋建筑，办公、住宅及公共服务；数据由同一个确定性生成器产生，并可导出 JSON 供 Blender 使用。
- 模拟遥测按时间刷新，控制和运维记录本地持久化。数据损坏时安全恢复初始状态。
- 告警定位 → 诊断 → 派单 → 处理 → 复盘；人员访客、电子围栏、应急推演为可交互演示。

## 实施顺序
1. 数据模型、空间生成器、业务状态机及核心测试。
2. Three.js 沙盘、建筑剖切、设备点位、管网、疏散与模型导入。
3. Vue 管理工作台、房间控制、业务专题、模拟实时数据。
4. Blender 建模与 glTF 导出脚本、接入说明。
5. 测试、生产构建和浏览器交互验证。

## 验收
建筑/楼层/房间可选；每间房间有面积、用途、人数、设备和模拟遥测；告警定位到房间并完整流转；控制可持久化；专题切换产生业务变化；疏散路径标记出口与集合点并说明估算限制；模型导入验证绑定；构建及核心测试通过。

## 真实落地边界
真实接入需要后端身份权限、审计、时序数据库、物联网网关、协议适配与视频服务。应急演示不替代专业消防设计或安全评估；该项目不直接控制任何物理设备。
