# 未来院区 / Future Yard — 品牌与 Logo 指南

## 设计含义 / Concept

Logo 将实体楼宇、数字孪生轮廓和感知节点组合为一个等轴测图形。实心立方体代表可钻取的建筑空间，虚线六边形代表数字映射，右上角节点代表设备遥测与空间连接。独立底色保证图形在 GitHub 的浅色 / 深色主题和应用页头中清晰可见。

The isometric symbol combines a physical building, a digital twin outline and a sensing node. The solid cube represents navigable spaces, the dashed hexagon represents their digital mapping, and the upper-right node represents device telemetry and connectivity. A built-in dark background keeps the symbol readable in both GitHub themes and the application header.

## 使用规范 / Usage

- 保持原始比例，不拉伸、旋转或裁掉感知节点。 / Preserve proportions; do not stretch, rotate or crop the sensing node.
- 独立 Logo 建议至少 32 px；favicon 可以更小，小尺寸下以轮廓辨识为主。 / Use at least 32 px for the standalone logo; favicons may be smaller and emphasize the silhouette.
- Logo 周围保留约图形宽度 1/8 的净空。 / Leave approximately one-eighth of the symbol width as clear space.
- 横幅使用完整底色，不叠加在复杂图片上。 / Keep the banner background and avoid layering it over busy images.
- 中英文文档保持相同图形、配色与信息结构。 / Keep the same symbol, colors and information structure in both languages.
