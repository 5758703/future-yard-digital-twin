# 空间、设备与外部系统接入规范

## 当前实现
Vue 3 管理响应式业务状态，Three.js 负责场景渲染、拾取、剖切和 glTF 导入。Blender 脚本根据相同 JSON 生成独立可编辑模型。前端独立运行，所有控制仅修改模拟数据；浏览器 localStorage 保存房间控制、告警处理、访客记录。

## 空间坐标与 ID
- 单位：米；Three.js X/Y/Z = 东/上/南的局部示意坐标，不是经纬度。
- 建筑 `A`～`F`，楼层 `A-F3`，房间 `A-301`，设备 `A-301:smoke`。
- 楼高 3.6 m，室内净高 3.3 m；楼层标高 `(楼层号 - 1) × 3.6`。
- `width` / `depth` 为房间平面尺寸；房间使用面积不含中央走廊，建筑总面积按每层建筑矩形外轮廓求和。
- Blender 用 Z 向上，脚本把 `(x,y,z)` 映射为 `(x,-z,y)`，glTF 导出后恢复 Three.js Y 向上。
- GLB 自定义属性（extras）包含 `buildingId`、`floorId`、`roomId`；导出时必须启用 Custom Properties / `export_extras=True`。
- 自定义 GLB 必须内嵌所有资源且小于 100 MB。导入时要求有效 `buildingId`，避免无法关联业务数据的裸模型。院区层采用导入外观，室内钻取采用标准空间生成器，以保证业务一致；未实现对任意外部 BIM 自动识别楼层。

## 推荐生产 API（接口契约，非已运行后端）
```text
GET  /api/campuses/FY/spaces        建筑、楼层、房间、坐标、BIM版本
GET  /api/devices?roomId=A-301      设备台账与状态
GET  /api/telemetry?roomId=A-301    当前遥测
GET  /api/energy?buildingId=A&from=...&to=...  历史时序
POST /api/devices/:id/commands     控制请求，返回命令 ID
POST /api/alerts/:id/transitions   告警状态变更与审计
POST /api/visitors                访客登记及授权空间
GET  /api/cameras/:id/playback     经授权的视频地址
WS   /api/events                  遥测、告警、门禁、命令回执
```

遥测事件示例：
```json
{
  "type": "telemetry",
  "deviceId": "A-301:temperature",
  "roomId": "A-301",
  "timestamp": "2026-09-23T01:42:18.000Z",
  "quality": "good",
  "values": { "temperature": 25.1, "humidity": 54 }
}
```

控制命令必须由网关确认后更新真实设备状态；后端实施身份认证、按院区/楼栋授权、命令白名单、防重放、幂等性、超时与审计。不要把设备凭据放入前端。推荐通过网关把 BACnet / Modbus / MQTT 等协议转换为受控 API。

## 模拟业务算法
- 遥测由稳定哈希与随时间变化的正弦生成；灯光与空调开关影响模拟功率，设定温度影响模拟室温。
- 24 小时用能曲线是合成历史数据，当前控制不会追溯修改历史。节能建议关闭当前范围内无人房间的照明和空调。
- 告警遵循 `new → diagnosed → assigned → resolved → closed`，不能跳步，处理必须填写记录。闭环后解除空间告警色，历史仍保留。
- 人数是每个房间生成的有界模拟人数；访客数据独立管理，不暗示真实人脸识别或实际定位能力。
- 访客电子围栏是授权楼栋与模拟越界状态演示，真实接入需定位/门禁事件、时间窗与防抖规则。
- 疏散路径按“房间 → 走廊 → 楼梯 → 室外消防车道 → 集合点”生成。估时为路径长度 / 1.1 m/s + 楼栋人数 / 通行率，楼梯封堵时通行率从 2.6 降至 1.3 人/秒。备用路线长度可能缩短，但排队时间增加。未模拟烟气、实际门宽、人群避障或垂直步速，不能用于现实消防决策。

## 文档需求覆盖和演示边界
| 文档功能 | 项目交付 |
| --- | --- |
| 院区三维底座 | 建筑、道路、绿化、运动场、停车、消防、集合点、管网示意 |
| 楼栋/楼层/房间管理 | 双向选择、分层、剖切、家具、尺寸、用途、容量 |
| 五大专题 | 安防、楼控、能源、后厨、公共设施，可切换的业务面板 |
| 设备数据上图 | 房间绑定设备、遥测、摄像头/消防点位，台账与维护日期 |
| 智能控制与趋势 | 房间照明、空调开关和温度设定、能耗曲线与无人空间节能 |
| 告警闭环 | 房间定位、诊断、派单、处理、复核、审计时间线 |
| 访客与电子围栏 | 登记、楼栋授权、越界/返回模拟、签退 |
| 应急演练 | 可视化路线、集合点、备用楼梯、容量与时间估算 |
| 视频监控/后厨 | 明确标识的合成监控示意，后厨温度/燃气/净化效率模拟 |
| 真实设备联动/故障预测 | 提供空间绑定、阈值诊断和接入契约；不声称真实协议接入或训练过的预测模型 |
| 暖通详细运行与天气预测 | 房间 VRV、温度、空调负荷、COP、风机转速、供暖负荷及天气预测示例；均为可说明的模拟规则，真实数据待后端接入 |
